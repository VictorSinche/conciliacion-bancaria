# Sistema de Conciliación Bancaria

Proyecto final desarrollado en Python con SQLite para automatizar el registro, consulta y conciliación de movimientos bancarios con comprobantes de pago.

## Integrantes y módulos

- Victor: Módulo de transacciones bancarias.
- Liz: Módulo de comprobantes de pago.
- Marco: Módulo de conciliación semi-automática.
- Jesús: Módulo de estadísticas.

## Funcionalidades principales

El sistema permite:

- Registrar, listar y buscar transacciones bancarias.
- Registrar, listar y buscar comprobantes de pago.
- Ejecutar una conciliación semi-automática entre transacciones y comprobantes.
- Guardar conciliaciones encontradas en la base de datos.
- Consultar estadísticas sobre montos conciliados, facturas conciliadas e ingresos por mes.
